# PickLoop 검증 결과와 제출 안내

확인일: 2026-11-18 (Asia/Seoul).

## 실행 결과

동일한 5개 seed × 12개 조건 × 2개 정책, 총 120회 실제 MuJoCo 실행. 완료율: 기준 10/60 (16.7%) → 복구 50/60 (83.3%).

복구율은 첫 시도 작업 미완료 50건 중 40건, 80.0%. 영구 흡착 실패와 미등록 품목 주문도 분모에 포함했다. 잘못된 배치0, 금지 충돌0. 낙하 장애는 양쪽 정책에서 각각5건 발생했으며 복구 정책에서는 낙하 후 다시 집어 완료했다.

평균 작업 종료 시간(실패 포함)은 기준 5.37초, 복구 20.72초의 시뮬레이션 시간이다. 복구는 더 오래 시도한다. 이 합성 조건 혼합에서 sim 처리량 111.7→144.8건/시간이며 현장 생산성을 의미하지 않는다.

조건별 성공은 각 seed에서 동일해 완료율의 seed 간 표준편차가0이었다. 5개 seed와 결정론적 장애 주입의 제한이며 안정성 보장으로 해석하지 않는다. 위치 오차·wall 시간·Wilson 구간·원본 행은 metrics.json/trials.csv에 모두 있다.

## 테스트와 구현

- Python 자동 테스트73개, UI 계약 검사13개 통과. 외부 Starlette/AnyIO deprecation warning1개가 있으며 시험 실패는 아니다.
- 실제 C++17 Modbus TCP 통신, 명령 중복·응답 유실·재연결·취소·영속 복구.
- 실제 ROS2 Jazzy 컨테이너의 Action 정상/취소/중복 요청, DDS 카메라·관절·clock 수신.
- 모바일 운동학 시뮬레이션에서 EKF 측위·A* 경로·도킹 gate 후 같은 물리 피킹 엔진 실행, 셀 퇴장과 두 번째 로봇 작업.
- 실제 CNN 훈련/체크포인트와 TorchScript 비교. 마지막 합성 평가 known240/240·지정 unknown120/120. 실제 창고 일반화 결과 아님.

## 데모와 접근

[배포된 운영 데모](https://pickloop-robot-ops.ykh13571.chatgpt.site)는 사용자의 명시적 공개 승인 후 링크를 아는 누구나 로그인 없이 열 수 있도록 설정했다. Sites 접근 설정 결과 access_mode=public을 확인했다. 새 조건 계산은 로컬 실행 서버에서 제공하고, 배포 화면은 저장된6개 실행만 재생한다.

67.5초 MP4는 정상 → 흡착 실패 후 복구 → 영구 실패 보류의 실제 물리 장면과 RGB-D 카메라를 함께 보여준다. 작업ID·sim timestamp·압력·최종 결과·source hash가 포함된다.

Sites 배포는 도구에서 succeeded로 확인했다. 관리형 미리보기 relay timeout과 브라우저 runtime unavailable 때문에 배포 UI를 실제 브라우저에서 직접 클릭·시각 점검하지 못했다. HTML/JS 계약 검사는 통과했지만 브라우저 QA와 모바일 viewport 스크린샷은 미완료다. 실제 시뮬레이션 영상은 디코딩·프레임 시각 검사를 했다.

## 증거·기여·한계

소스 ZIP의 README에 설치/실행/동일 평가 재현 명령이 있다. runs/final에는 실행 전 동결 manifest, 120개 result.json/events.jsonl, 집계 JSON/CSV/표가 들어 있다. web/data에는 데모 실제 프레임과 이벤트가 있다. ROS2/mobile 증거와 독립 코드 리뷰/회귀 수정 기록도 포함했다.

핵심 실행 source commit: 6b4d93e165add7932e1897885f6126f81288971c. 모든 최종 평가 run의 source SHA256가 동결 manifest와 일치한다: `4108010f88b6d6bd8cd5b547bde9ee3fac7c4fc5cc4ab2ea9fad3be3515469e3`.

공고 원문과 기존 저장소 구현을 조사했다. ReachBench가 이미 실제 pick/place를 구현했다는 점을 반영해 신규 기여를 구분했다. 사용자 PCB 경험은 확인된 PADS·ATmega128 회로/배치/배선과 도구 검증으로만 서술했다. 이번 코드는 AI가 작성·실행한 것으로 기여 기록에 명시했다.

실물 로봇 모델 배포·진공/안전 회로·실제 SLAM·도킹/충전·KiCAD 경험을 수행했다고 주장하지 않는다. 고정 카메라 PnP 외부 보정이며 hand-eye AX=XB가 아니다. 모바일와 팔은 별도 세계를 작업 gate로 연결했다. 실물 인수시험과 I/O 후보 인터페이스는 준비했으나 제작·전기적 시험은 미수행이다.

GitHub의 sokldjs554/pickloop 저장소 생성·push와 원격 CI 실행은 수행하지 않았다. 로컬 소스, CI 정의, 실행 자료와 배포 데모를 제공한다.

초기 비교 실행은 영상 기록과 CPU를 공유한 사실을 발견해 결과를 집계하기 전에 전체 실행을 중단·격리했다. 코드·seed·평가 기준을 바꾸지 않고 데모 기록 종료 후 전체120회를 순차 재실행했다. 최종 결과를 보고 훈련이나 정책을 조정하지 않았다.
