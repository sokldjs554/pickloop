## 재생·보류·기존 기술 증거

공개 화면은 사전 지정한 첫 seed3000의 7조건 × 4정책 = 28개 대표 실행을 다시 기록했다. 전체 576회 원평가는 조건별 표에서 별도로 열 수 있다. 대표 재생은 성능 통계에 다시 포함하지 않는다.
최초 재생 기록과 원평가의 조건/초기 상태/소스/모델을 검증했다. 결과·원인·재시도·sim 시간까지 일치한 기록은 27/28개다. 차이가 있으면 화면에 표시하며 성공할 때까지 바꿔치기하지 않는다.
- 차이 기록: `suction_once-3000-naive-d3909b` → 원평가 `suction_once-3000-naive-b58a9f`; `{'condition': True, 'initial_truth': True, 'success': False, 'reason': False, 'retries': True, 'sim_delta_s': 12.399999999998611, 'source': True, 'model': True}`

지속 흡착 실패 48회 중 빈 흡착기 OFF 확인 48회. 정지 후 새 장치 상태로 분리·약한 압력·명령 응답을 확인한 경우에만 OFF를 보낸다. 부하·출력 불확실이면 유지하며 STOP_REPORT, RETRY_EXHAUSTED, HOLD_POLICY를 따로 기록한다. 이 판단은 물리 정지/단일 명령 작성자의 시뮬레이션 전제이며 실물 원자적 release interlock이나 안전 인증은 아니다.

화면은 완료 단계 이력을 보존하고 실패/시도 소진/보류를 분리한다. 실패·재시도·배치 점프, 같은 경과 시간의 나란히 재생, −35kPa 판정선, 한국어 이벤트, 비확률 진단점수와 미등록 기준 안내, 첫 화면 집계 및 상세 ID/원문을 제공한다.

ROS2 Action/DDS·C++ Modbus TCP·모바일 측위/도킹의 기존 실행 증거를 5개 카드와 원문 링크로 노출했다. 새 실물 연결을 주장하지 않는다.
