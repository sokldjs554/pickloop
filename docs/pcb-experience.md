# 사용자 PCB 제작 경험 — 확인된 사실과 미확인 사항

2026-11-18 대화에서 사용자가 제공한 내용:
- MCU: ATmega128.
- 설계 도구: PADS. KiCad 사용 경험으로 바꾸어 적지 않는다.
- 수행: 회로 설계, 부품 배치와 배선, 검증 실행에서 `success` 확인.
- 문제 해결: 처음에는 배선이 복잡하여 부품을 재배열하고 다시 배선했다. 결과가 정돈되지 않아 숙련된 동료에게 조언을 구하고 다시 시도하여 더 깔끔한 배선을 완성했다.

아직 확인되지 않은 내용: 보드 용도/제작 시기, PCB 발주·가공·실장 여부, 펌웨어 개발 범위, 사용한 측정 장비, `success`가 의미한 검사 종류(DRC/연결성 검사/시뮬레이션/실물 기능 시험), 실물의 전기적 동작 측정 결과. 따라서 현재 증빙은 회로·레이아웃·배선과 도구 검증 경험으로 한정하며, 실물 로봇 통합·오실로스코프 측정·하드웨어 제품 양산 경험으로 주장하지 않는다.

## 지원서에 사용할 수 있는 문장

“PADS와 ATmega128을 사용한 회로 설계 및 부품 배치·배선을 경험했습니다. 배선 복잡도 문제를 부품 재배치로 개선했고, 숙련된 동료의 피드백을 반영해 배선을 정리한 뒤 설계 검증의 성공 결과를 확인했습니다. 이 과정에서 부품 배치가 연결성·배선 품질과 검증에 미치는 영향을 배웠습니다.”

PCB 결함 검사 GitHub 프로젝트는 별도 컴퓨터 비전 프로젝트다. 위 설계 경험과 동일한 보드·동일 프로젝트라고 연결하지 않는다. PickLoop에는 신규 흡착 I/O 인터페이스 명세·실물 시험 절차를 제공하지만, 기존 ATmega128 보드가 PickLoop와 연결되어 작동했다고 기재하지 않는다.

[KiCad 벤치 실습 자료](../hardware/kicad-pressure-bench/)는 Codex가 추가했다. 회로·PCB를 열어 150 Ω 저항의 전압 계산과 ERC/DRC를 직접 비교할 수 있다. 사용자의 경험 항목은 위에 확인된 PADS 작업에 근거한다.
