# 전체 상품 등록 실험 명세

공식 Grocery Store Dataset의 세부 라벨 81개를 같은 모델에 등록한다. 실제 사진만 판별기에 전달하고 정답과 파일 경로는 판정 뒤에 대조한다. 예전 두 주스 실험에서 미등록이던 2,656장과 등록이던 56장은 SHA-256으로 짝지어 새 판정을 확인한다. 등록 수와 사진별 정답 수는 따로 센다.

- 등록에는 공식 train만 사용한다. 세부 품목별로 파일 순서에서 연속 약 20%를 개발용으로 보관한다. 블록 위치는 품목 ID에서 결정한다. 공식 val·test·카탈로그 사진은 전부 평가용으로 남긴다. 과거에 이미 본 데이터셋에서 다른 과제(81개 이름 분류)를 평가한다.
- 공개 DINOv2 ViT-S/14의 가중치를 동결한다. 전체 사진의 분류 토큰, 중앙 패치들의 평균, 중앙 영역의 색 분포를 이용한다. 81개 이름 사이의 선형 판별과 등록 사진 유사도를 조합한다.
- 학습 내 개발 사진으로 분류 설정을 선택한다. 외부 미등록 사진 중 보정용과 평가용은 상품군 단위로 나눈다. 보정 전 맞힌 개발 사진의 최소 95%를 유지하는 범위에서 미등록 보정 사진의 거부를 최대화한다. 동률이면 등록품 정답을 더 많이 유지하는 조건을 우선한다. 목록 밖 상품의 오수락을 별도 보고한다.
- 최종 모델과 판정 기준을 저장한 뒤 공식 시험 2,485장, 검증 296장, 상품 대표 사진 81장, 외부 미등록 평가 사진을 채점한다. 품목별 정답·다른 이름으로 오분류·보류 및 사진별 예측을 공개한다. 로봇 제어와 두 주스 전용 실험은 별도의 실행 경로다.
