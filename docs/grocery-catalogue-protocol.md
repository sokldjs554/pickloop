# 전체 상품 등록 실험 명세

공식 Grocery Store Dataset의 세부 라벨 81개를 같은 모델에 등록한다. 실제 사진만 판별기에 전달하고 정답과 파일 경로는 판정 뒤에 대조한다. 예전 두 주스 실험에서 미등록이던 2,656장과 등록이던 56장은 SHA-256으로 짝지어 새 판정을 확인한다. 등록 수와 사진별 정답 수는 따로 센다.

- 등록에는 공식 train만 사용한다. 세부 품목별로 파일 순서에서 연속 약 20%를 개발용으로 보관한다. 블록 위치는 품목 ID에서 결정한다. 공식 val·test·카탈로그 사진은 전부 평가용으로 남긴다. 과거에 이미 본 데이터셋에서 다른 과제(81개 이름 분류)를 평가한다.
- 공개 DINOv2 ViT-S/14의 가중치를 동결한다. 전체 사진의 분류 토큰, 중앙 패치들의 평균, 중앙 영역의 색 분포를 이용한다. 81개 이름 사이의 선형 판별과 등록 사진 유사도를 조합한다.
- 학습 내 개발 사진으로 분류 설정을 선택한다. 외부 미등록 사진 중 보정용과 평가용은 상품군 단위로 나눈다. 보정 전 맞힌 개발 사진의 최소 95%를 유지하는 범위에서 미등록 보정 사진의 거부를 최대화한다. 동률이면 등록품 정답을 더 많이 유지하는 조건을 우선한다. 목록 밖 상품의 오수락을 별도 보고한다.
- 최종 모델과 판정 기준을 저장한 뒤 공식 시험 2,485장, 검증 296장, 상품 대표 사진 81장, 외부 미등록 평가 사진을 채점한다. 품목별 정답·다른 이름으로 오분류·보류 및 사진별 예측을 공개한다. 로봇 제어와 두 주스 전용 실험은 별도의 실행 경로다.

## 1차 평가 후 보류 기준 재검토

첫 평가에서 등록품이 보류되는 현상을 확인했다. 첫 81품목 모델은 커밋 `9580db0`에 보존했고, [첫 결과](experiments/grocery-catalogue/first-pass.json)를 함께 남긴다. 후속 비교에서 임곗값 후보에 외부 보정 사진 점수의 상위 경계도 넣는다. 기존에는 등록품 개발 사진 점수만 후보로 삼아, 계산 가능한 경계 사이 값을 비교하지 못했다. 음성 점수 상위 절반에서 최대 17개 경계를 고르고, 사진 한 장과 배치 계산의 부동소수점 차이를 고려해 각 점수에 0.00001을 더한다. 모델 구조·분류 설정·목적함수·95% 유지 조건 및 분할은 그대로 적용한다. 외부 보정 176장과 학습 내 개발 529장으로 임곗값을 결정해 저장한 후 같은 평가 사진에 재적용한다. 동일 자료를 다시 본 비교이므로 새 독립 시험으로 해석할 수 없다.

## 기존 등록 주스의 판별 동작 유지

일반 81종 분류기의 1위가 기존 Bravo 사과·오렌지 주스 중 하나이면, 이전에 고정한 인쇄 면·색 검증기의 결과로 최종 이름 또는 보류를 결정한다. 일반 수락 기준을 통과하지 못한 Bravo 후보도 인쇄 면을 검증한다. 다른 79개 후보는 일반 분류기의 결과를 사용한다. 이전 기록에서 이름을 복사하지 않고 원본 사진으로 검증기를 다시 실행한다. 과거 두 주스 실험에서 선택한 등록 특징, 인쇄 면 임계값을 그대로 사용하며 새로 조정할 매개변수는 없다. 이 통합을 결정할 때 같은 시험 사진에서 단독 모델의 퇴행을 확인했으므로 모든 통합 수치는 재분석이다.
