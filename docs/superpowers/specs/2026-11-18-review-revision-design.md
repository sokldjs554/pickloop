# PickLoop 사용자 리뷰 수정 설계

사용자가 직접 검토한 공개 화면의 6개 문제와 보류 출력 상태, 기존 기술 실행 증거를 보완한다. 기존 회색/청록색과 실행 원문 연결을 유지한다. 추가 제품 기능은 만들지 않는다.

## 구현 판단

원래 1회 대 3회 비교만 유지하는 방식은 시도 예산을 통제하지 못한다. 3회 단순 재시도만 추가하면 센싱과 경로 변경의 기여가 섞인다. 따라서 구현자가 4정책 절제 실험을 선택했다: baseline 1회, naive 최대 3회 고정 파지 좌표/경로, reobserve 최대 3회 재관측/고정 경로, recovery 최대 3회 재관측/재시도 경로 높이 변경. 사용자의 동일 예산 비교 및 재관측·재계획 효과 분리 요구를 구체화한 판단이다.

정책별 최대 시뮬레이션 60초, wall 90초, 압력/신선도/충돌 보호 동일. 안전 정지는 끝까지 수행하며 시간에 포함. 대상 미검출 시 naive도 관측 재시도 가능. 최초 유효 목표 이후 좌표를 고정한다. 이는 특정 명시적 절제 정책이며 산업 최적 정책이라는 주장은 하지 않는다.

새 조건 파일은 배치·자세·가림·깊이·보정·흡착·장애 지속시간을 사전에 고정한다. 장애가 시도 횟수에 따라 해제되는 기존 방식은 새 실험에서 사용하지 않는다. 개발 seeds 200..209, heldout seeds 3000..3011 및 분포를 구분한다. 최종 측정 전 코드/조건 해시를 동결하고 이후 결과에 맞춰 튜닝하지 않는다. 기존 120회 결과는 과거 실험으로 보존한다.

보류에서 확인된 빈 흡착기는 OFF, 부하 또는 상태 불확실은 유지. 시뮬레이터 물리 정지와 단일 명령 작성자라는 전제 아래 처리하며 실물 안전 인증으로 표현하지 않는다.

화면은 동시 비교 재생, 핵심 이벤트 이동, -35 kPa 기준, 완료 단계 이력, 비확률 인식 점수, 기존 ROS2/C++/모바일 원문 증거를 노출한다. 실제 관측 프레임만 사용한다. 새 metrics 및 대표 replay의 일치 여부를 명시한다.
