# PickLoop Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent modules; root integrates and verifies.

**Goal:** Physics-based perception-to-placement with bounded recovery, paired evaluation and honest operator replay.
**Architecture:** CPU MuJoCo SCARA + RGB-D perception + learned embedding + BT executor + TCP Modbus + event journal. Static evidence replay and local FastAPI live runner share event contract.
**Tech Stack:** Python 3.12, MuJoCo, NumPy/OpenCV/PyTorch, py_trees, FastAPI, C++17, browser HTML/CSS/JS.
**Spec:** ../specs/2026-11-18-pickloop-design.md

## Global Constraints
- All distances m, joints rad, durations s; explicit optical/base frames and stamped observation IDs.
- Control never receives simulator object IDs/poses; truth restricted to physics and evaluator.
- Original work and user contributions are distinguished. No invented hardware experience.
- Baseline/recovery share seed/fault; frozen final seeds distinct from development.

## Review Focus
- Lost command acknowledgement must not cause a second actuator execution.
- Restart with an active job must require reconciliation and never silently repeat a pick.
- Stale/missing depth must reject a motion goal and bounded retry must terminate.
- Cancellation while gripping must stop and preserve support instead of dropping an object.
- Final placement must require visual verification and independent truth evaluation.
