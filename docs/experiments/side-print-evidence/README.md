# 기존 매장 사진의 옆면 판독과 미등록 유사 상품

스웨덴 매장 사진에서 옆면이 보이는 등록품 15장을 같은 파일로 전후 비교했다. 앞면 일부가 함께 보이는 사진도 포함한다. 촬영자가 다른 매장에서 사과·혼합주스 팩의 전체 옆면을 찍은 새 사진은 각각 0건이다. 이 표는 개발 중 살펴본 원본의 재시험 결과다. [옆면 15장의 원본 링크와 판정](side-photos.csv) · [기준 판독기(v28)](../side-panel-retry/) · [이번 판독기 브라우저 원문 118건](browser.jsonl)

| 브라우저에서 읽힌 상품명 | v28 정답 | 이번 정답 |
| --- | ---: | ---: |
| 사과 1 L 옆면 | 1/2 | 1/2 |
| 오렌지 1 L 옆면 | 3/8 | 6/8 |
| 오렌지·레드자몽 1 L 옆면 | 4/5 | 5/5 |
| 등록품 옆면 전체 | 8/15 | 12/15 |
| 등록품 앞면 전체 | 32/45 | 32/45 |

**혼합주스.** 반사 때문에 맛 이름의 뒷부분이 흐린 사진에서는 같은 팩의 브랜드 인쇄와 뚜껑 아래 두 과일 무늬를 대조했다. 참조 사진은 훈련 세트에서 가져왔다. 과일 무늬만 지우거나 옆 상품으로 옮긴 대조 사진에서는 이름을 보류했다. [확인한 무늬와 가림 실험](../split-fruit-collar/)

**오렌지.** 한 장은 앞면과 이어진 성분표를, 두 장은 맛 이름 아래의 인쇄와 옆면 영양표의 줄바꿈을 대조해 판독했다. 핀란드 1 L와 스웨덴 1.75 L에도 비슷한 오렌지 그림이 있어 과일 그림만으로 규격을 고를 수 없다. [인쇄 위치와 유사 상품 대조](../orange-side/)

**사과.** 두 장 중 한 장은 v28부터 옆면 바코드가 읽혔다. 나머지 한 장에서는 용량과 바코드가 읽히지 않았다. 이 사진의 원재료 글줄을 두 용량의 실제 인쇄와 비교했을 때 1.75 L가 더 비슷했고, 바코드로 확인한 1 L 대조 사진에서도 같은 현상이 발생했다. [원본 사진과 비교 수치](apple.md)

**미등록 상품.** 별도로 모은 실물 사진 16장에서는 등록 상품명 오인과 잘못된 주문 확정이 각각 0건이었다. 핀란드 사과주스 1 L 한 장은 이전 판독기가 스웨덴 등록품 이름을 붙였던 사례여서 오류 분석 후 재시험한 대조 사진으로 표시했다. 짧은 바코드 11장의 형식 시험과 미등록·등록 코드가 함께 있는 주문 시험은 별도로 수행했다. [미등록 실물 사진 전후 기록](../side-unknown-challenge/) · [짧은 바코드와 주문 판정](../short-retail-codes/) · [별도 Python 판독기의 33장 전후 비교](../market-rival-retry/)
