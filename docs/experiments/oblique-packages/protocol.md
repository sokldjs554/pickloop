# Oblique package evaluation protocol

The primary pair is the shipped reader versus the final candidate on **all 15 originally labelled side-visible registered test photographs**. Freeze the original view labels, input bytes and cohort membership. Count a correct ordinary consumer-facing name for the foreground target. Keep each original failure, including mixed shelves and unreadable panels. Also score all 45 registered fronts, all 14 archived plain-red-grapefruit controls, both public apple retests and all six public lookalikes. Report Python and Chromium separately. For each stratum report correct names, holds, names of the wrong registered product, names of the wrong broader-catalogue product, correct broader-catalogue names, strict confirmations and paired gains/losses. Only GTIN 7310860007396 can receive the correct broader-catalogue name God-Morgon-Red-Grapefruit-Juice in these cohorts. Python strict mode records independently confirmed order SKUs. Browser replay records the barcode order displayed by the upload form.

The unchanged archive, negatives and public retests are historical development/regression measurements. The archive contains correlated frames of a foreground carton against shop shelves. The number of separate cartons and camera sessions is unknown. The prior acquisition audit flagged nine plausible same-flavour settings among training additions and archive photos. Report the primary side comparison again after excluding these flags, with its smaller denominator. Never pool archive frames, previously viewed validation photographs, publisher retests and fresh acquisitions into an independent accuracy estimate. Publish every paired row and both direction changes.

For supplemental real images, identify the foreground product independently of recognition output, with source URL, product record, image hash, material view and acquisition group. Group the same uploader/session and related views of one object conservatively. Keep re-encodings, alternate crops and supplier mirrors with their original composition. Reject a claimed new registered positive if its exact Swedish 1 L identity or new acquisition cannot be established. Physical scale, provenance and result from an external adjudicator take precedence over a filename or marketing description. Inspect original bytes, labels, reference/development inventories and view before scoring. Report the count of verified new positives even if zero. Separate results on fresh negative groups, legacy validation and generated transformations. Generated oblique examples can measure robustness to a specified transformation only.

Do not tune a candidate on the supplemental outcomes and then count its results on those same groups as independent. Mark any seen group as a retest if further changes use its output. Runtime uses only measured wall times with field and denominator given. Missing baseline timing remains missing.
