# 제품 앞면이 온전히 보이지 않을 때의 판독

이전 브라우저 판독기가 모두 보류한 같은 상품의 다른 구도 9장을 개발 자료로 사용했습니다. 사진의 URL·파일명·정답 코드는 판독기에 전달하지 않았습니다. 파일 선택창에 원본 바이트를 넣고 표시된 이름과 주문 판정을 기록했습니다. [원본 주소와 해시](../foreground-titles/supplement-sources.csv) · [수정 전](../foreground-titles/supplement.jsonl) · [수정 후](original.jsonl)

| 입력 | 미등록 근거가 나온 사진 | 근거 부족 보류 | 잘못된 등록 이름·주문 |
|---|---:|---:|---:|
| 다른 구도 개발 사진 9장 | 4 | 5 | 0 |
| 판독 가능한 4장을 8도 회전·재압축 | 2 | 2 | 0 |
| 추가 공개 사진 3장 | 1 | 2 | 0 |

- 원본에서는 만다린·당근 성분표, 포도·엘더플라워 성분표, 현지어 만다린·당근 앞면, 두 언어의 오렌지주스 1.75 L 용량을 구별했습니다. 남은 사진은 영양표 3장, 인증 마크 1장, 환경 안내문 1장입니다.
- 회전 시험은 위 네 원본을 PIL에서 가로·세로 최대 1600 px로 줄인 뒤 흰 배경에 8도 회전(BICUBIC, expand=True), JPEG 품질 87로 저장했습니다. 기울기 보정 전에는 0/4, 보정 후 현지어 앞면과 엘더플라워 성분표에서 2/4입니다. 같은 원본을 변환한 스트레스 시험입니다. [보정 전](tilted-before.jsonl) · [보정 후](tilted.jsonl)
- 다른 공개 사진 3장은 이번 규칙 개발에 사용하지 않았습니다. 블러드오렌지의 유사 포장 한 장을 기존 판독 경로가 구별했습니다. 이 중 두 장은 프로젝트의 이전 실험에도 등장합니다. [원본](extra-sources.csv) · [판정](extra.jsonl)
- 등록 대조 사진 6장에서는 등록 사진 판정 5장, 보류 1장, 미등록 판정 0장이었습니다. [대조 기록](registered-controls.jsonl)

등록 목록과 양립할 수 없는 성분 조합이나 용량 표기가 있어야 추가 판독이 작동합니다. 앞선 바코드 결과와 포장 충돌 판정을 유지하고, 글자로 읽은 성분·용량은 피킹 주문을 발행하지 않습니다. 새 매장의 사과·혼합주스 전체 옆면 촬영 자료는 각각 0장입니다.
