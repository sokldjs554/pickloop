# 운반 높이 변경에 대한 독립 시뮬레이션

사용자는 개발 seed 200에서 직접 코드를 수정하고 수정 전후 실행 기록을 비교했다. 이 문서와 CSV는 Codex가 별도 환경에서 같은 규칙을 구현하고 개발 seed 201~209를 독립 실행한 결과다.

기준 코드는 `sokldjs554/pickloop`의 `cd951bd`다. 비교 코드는 `Controller.transport_height`에서 recovery 정책의 두 번째 이상 시도 중 직전 오류가 PATH_BLOCKED일 때만 0.40 m를 선택하고, 그 밖에는 0.30 m를 선택했다. 각 버전에서 `python lab.py run <새 폴더> --seed <seed>`를 실행했다. 같은 seed, 조건 ID, 정책, 모델 해시가 일치하는 다섯 작업씩 총 45쌍을 비교했다.

| 관측 항목 | 기준 | 변경 후 |
|---|---:|---:|
| 완료 | 27 | 27 |
| 보류 | 18 | 18 |
| 충돌 / 낙하 / 오배치 | 0 / 0 / 0 | 0 / 0 / 0 |

45쌍 모두 종료 상태가 같았다. 경로 차단에서 재계획한 작업은 9쌍 모두 완료했다. 보정 오차에서는 한 번 재시도한 7쌍에서 각각 2.530 시뮬레이션 초를 절약했다. seed 203과 208은 첫 시도에 완료해 시간이 같았다. 나머지 조건의 시뮬레이션 시간도 표시 정밀도 0.001초에서 같았다.

해석 범위는 이 개발 조건과 다섯 가지 작업·정책 조합이다. 보류된 작업의 조기 종료를 시간 개선에 포함하지 않았다. 실물 로봇에서의 성능은 별도 검증 대상이다.
