# 뚜껑 아래 과일 무늬로 다시 확인한 혼합 주스

기존에 보류한 실매장 사진 `RR-d027f51d6376a638`에서 Chromium 작업자가 God Morgon 오렌지·레드자몽 1 L의 등록 포장과 일치한다고 판정했다. 영양 표시 위로 손이 겹치고 정면 맛 이름에는 반사가 있다. 뚜껑 아래에는 검은 틈을 사이에 둔 노란색과 분홍색 자몽·오렌지 조각이 보인다. 이 무늬의 휘도 표본은 별도의 매장 훈련 사진 두 장과 각각 0.9061, 0.9047의 상관을 보였다. 같은 포장의 브랜드 무늬 점수는 0.8192였고 투영에 일치한 대응점은 33개였다. 이 경로의 출력은 포장 사진 판정이다. [브라우저 결과](browser-diagnostics.json)

영어 Tesseract로 원본과 국소 대비를 높인 사진을 각각 −30°, 0°, +30°에서 확인했지만 여섯 판독 모두 혼합 맛을 식별할 단어를 얻지 못했다. 검출기는 사진 전체에서 틈, 두 조각의 색, 밝은 뚜껑, 아래쪽의 어두운 종이를 확인한다. 촬영 각도로 달라지는 모양은 회전·크기·기울기와 픽셀 사이의 보간으로 맞춘다. 한 위치에서 서로 다른 원본 두 장에 대한 상관이 모두 0.88 이상이어야 한다. 이 기준은 초기에 등록 자료로 정했고 정수 픽셀 검색부터 보간 검색까지 유지했다. 브랜드 쪽은 중앙의 포장 면에 대응점 16개 이상과 로고 점수 0.70 이상이 필요하다. 뚜껑이 그 면의 윗변에 있어야 한다. 경합하거나 다른 GTIN이 읽히면 기존 판정 절차가 보류한다. [훈련 사진 위치·원본 해시](enrollment.json) · [실행 파일 해시](source-hashes.json)

## 혼동하기 쉬운 제품

뚜껑 무늬만 단독으로 검색해 조사한 서로 다른 기존 사진은 142장이다. 혼합 주스 이외의 112장은 모두 기준 미달이었다. 이 검사에서 기준을 넘은 혼합 주스는 30장 중 19장이다. 이 수치는 로고·포장 위치·바코드를 포함한 브라우저 판정과 별도로 측정했다. 보류 사진의 개선을 위해 이미 확인한 자료로 구성된 개발·회귀 결과다. 다른 용량에서도 같은 디자인을 쓰는 경우를 구별하려면 읽을 수 있는 용량 표시나 상품 바코드가 필요하다. [사진별 무늬 점수](collar-only.csv)

| 사진군 | 혼합 주스 기준 통과 | 다른 제품 기준 통과 |
|---|---:|---:|
| 기존 매장 시험 사진 | 14/19 | 0/55 |
| 기존 검증 사진 | 4/6 | 0/14 |
| 기존 포장 사진 재검사(folds) | 1/5 | 0/9 |
| 기존 공개 사진 | — | 0/8 |
| 레드자몽 단일 맛 훈련 사진 | — | 0/26 |

기존 매장 시험군에 같은 브랜드의 레드자몽 단일 맛 14장이 포함된다. 이들의 최고 점수는 0.8174였다. 단일 맛 훈련 사진 26장의 최고는 0.8310이었다. 형태 변경 대조에서는 보류 사진의 뚜껑을 가리면 다시 보류했고 같은 뚜껑을 이웃 선반에 붙여도 보류했다. 두 대조 이미지는 원본 348×348에서 좌측 72, 상단 24, 우측 174, 하단 94의 직사각형을 어두운 RGB(38, 30, 26)로 가렸다. 이동 대조의 부착 위치는 좌측 228, 상단 18이다. 이 좌표는 검출기에 전달하지 않는다. 동일한 무늬를 사용하는 다른 용량·다른 유통 포장 전체를 검증한 자료는 없다. 주문 확정에는 기존의 바코드 절차를 사용한다. [대조 결과와 체크섬](browser-diagnostics.json)

## 같은 사진의 압축·밝기 변화

RR-d027 원본을 JPEG 품질 85로 저장하고, 같은 원본을 밝기 90%로 낮춘 뒤 같은 품질로 저장해 두 장을 만들었다. 첫 단계에서 두 번째 사진의 뚜껑 무늬 점수는 0.8763으로 기준 0.88에 미달했다. 원본 색을 유지하면서 무늬 중심과 투영 너비·각도를 함께 움직여 탐색하자 같은 위치에서 0.9055를 얻었다. 이 추가 탐색은 첫 점수가 0.84 이상 0.88 미만일 때 최대 2,025개 위치·모양 조합을 검사한다. 후보는 같은 기준 0.88을 통과하고 같은 팩에서 브랜드를 확인해야 한다.

| 같은 사진에 가한 변화 | 이전 파일 선택 결과 | 보완 후 파일 선택 결과 | 보완 후 주문 |
|---|---|---|---|
| JPEG 품질 85 | 혼합 주스 | 혼합 주스 | 보류 |
| 밝기 90% + JPEG 품질 85 | 보류 | 혼합 주스 | 보류 |

기존 142장의 뚜껑 무늬 검사도 다시 실행했다. 혼합 주스 30장 중 20장이 기준에 도달했고, 다른 상품 112장은 모두 기준 미달이었다. 새로 무늬 기준에 도달한 RR-d70e는 이전에도 브랜드와 맛 표기로 혼합 주스를 맞혔다. 이 한 건이 최종 상품 정답 수를 늘리지는 않는다. 위 두 변형은 같은 사진에서 만든 회귀 시험이다. 새 조명·새 매장에서 찍은 사진의 성공률은 이 실험으로 추정할 수 없다. [입력·판별기 해시, 사진별 전후값, Chromium 결과](pose-robustness.json)

## 재현

등록에 사용한 원본은 GroceryStoreDataset의 고정 커밋에서 가져온 공식 훈련 사진 네 장이다. 저장소에 제공하는 갤러리에는 각 사진에서 추출한 11×13 휘도 표본과 원본 해시가 들어 있다. 아래 명령은 프로젝트 루트에서 실행한다. `TRAIN`에는 등록 명세의 원본 JPG와 레드자몽 단일 맛 훈련 JPG를, `PHOTOS`에는 이전 시험·공개·검증·folds 명세의 사진을 ID 이름으로 준비한다. [원본 링크와 등록 표식](enrollment.json) · [기존 사진 명세](../registered-recall/)

```bash
python scripts/build_split_collar_gallery.py \
  docs/experiments/split-fruit-collar/enrollment.json "$TRAIN" /tmp/rebuilt-collar.json
cmp /tmp/rebuilt-collar.json web/data/registered-collar.json
node --test tests/split-collar.mjs
python docs/experiments/split-fruit-collar/replay.py "$PHOTOS" "$TRAIN" /tmp/collar-replay.csv
sha256sum /tmp/collar-replay.csv
```

위 마지막 해시를 `pose-robustness.json`의 `collar_only.replay_csv_sha256`과 대조한다. `collar-only.csv`와 `source-hashes.json`은 첫 단계의 기록이다.
