# 미등록 짧은 바코드와 주문 보류

브라우저의 파일 선택창으로 ZXing 공개 시험 자료의 `ean8-1`과 `upce-1` 두 묶음 전체를 실행했다. 이미지 11장에 서로 다른 상품 번호 10개가 있다. 이 자료는 바코드 형식을 검증하는 시험용 이미지다. 새 매장에서 찍은 주스 사진의 분모에는 포함하지 않는다. [원본·정답·SHA-256](inputs.csv) · [변경 전](before.jsonl) · [변경 후](after.jsonl)

| 입력 | 이전 브라우저 | 변경 후 브라우저 |
|---|---|---|
| 미등록 EAN-8 시험 이미지 8장 | 코드 판독 0/8 | 8/8 코드 판독 후 미등록 표시 |
| 미등록 UPC-E 시험 이미지 3장 | 코드 판독 0/3 | 3/3 코드 판독 후 미등록 표시 |
| 등록 주스와 미등록 EAN-8을 합친 시험 이미지 1장 | 등록 주스 250 mL 주문 확정 | 두 번호 표시 후 주문 보류 |

단독 입력 11장은 이전에도 주문이 보류됐다. 이번에는 화면이 판독한 번호와 미등록 사유를 표시한다. ZXing은 UPC-E를 확장한 번호로 반환한다. 판독기는 형식과 체크섬을 확인하고, 같은 번호의 중복 판독을 제거한 뒤 등록 목록과 비교한다.

마지막 입력은 기존 오렌지 주스 250 mL 실물 사진과 첫 번째 EAN-8 시험 이미지를 흰 배경에 나란히 놓은 합성 대조군이다. 서로 다른 두 코드가 보일 때 한 상품이 주문으로 확정되는 오류를 재현한다. 등록 주스 사진만 다시 넣으면 기존처럼 주문 규격이 확정된다. [단독 등록 사진 결과](registered-control.jsonl)
