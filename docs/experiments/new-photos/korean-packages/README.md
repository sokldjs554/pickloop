# 한국 식품 포장 앞면 원문 판독

신라면, 불닭볶음면, 초코파이 각 1장의 원본 사진을 Open Food Facts의 한국어 앞면에서 선택했다. 한국어 앞면이 없는 초코파이는 영문 앞면을 사용했다. OCR 전에 세 제품의 확인 단어를 고정하고 앞면에 실제로 보이는 범위도 기록했다. [선택 기준](protocol.json) · [원본 URL·업로더·해시](inputs.json) · [육안 기록](view-notes.json)

사진을 EXIF 방향에 맞춰 RGB로 변환하고 긴 변을 최대 2560픽셀로 줄여 PNG로 전달했다. 공개 브라우저용 엔진과 같은 한·영 데이터, 설정, WASM을 Node 워커에서 실행했다. 사진 변환은 Pillow에서 수행했다. [실행 도구](../../../../tests/package-reader-offline.mjs) · [판독 원문](worker-results.json)

- **신라면** · 눈으로 보이는 ‘라면’ 전체를 읽지 못했다. 하단 영문은 ‘SHIN RA,’까지 읽었다.
- **불닭볶음면** · 원본 오른쪽에서 제품명이 잘렸다. 한글 전체 이름이 출력되지 않았다.
- **초코파이** · 영문 ‘Choco Pie’ 포장이었다. 판독 원문에는 영어 전체 이름도 나오지 않았다.

제품 바코드가 보이는 앞면은 없었다. 세 사진 모두 코드가 검출되지 않았다. 이 세 장은 큰 장식 글자·부분 가림·영문 포장의 사례이며, 한국어 일반 정확도를 추정하기에는 표본이 부족하다. 원본은 제공처에서 내려받고 해시를 대조할 수 있다.
