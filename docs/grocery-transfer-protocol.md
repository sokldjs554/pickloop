# 실물 주스팩 인식 평가 사전 명세

비교 대상은 고정된 Grocery Store Dataset의 Bravo 사과·오렌지주스다. 앞선 거리 기준 강화 실험에서는 등록품 54장 중 3장이 정답이었고 미등록 포장 727장 중 36장을 받아들였다. 이번 실험의 개선 판정은 **동일 사진에서 등록품 정답이 3건보다 많고, 미등록 포장 오수락은 36건 이하**일 때다. 같은 포장 781장과 과일·채소 1,704장은 이미 결과가 알려진 재평가 집합이다. [기존 결과](real-photo-evaluation.md)

## 데이터 경계

- 공식 train의 두 주스(품목 ID 28, 29)를 학습한다. 등록되지 않은 포장 중 품목 ID가 3의 배수인 종류는 학습과 기준 설정에서 모두 제외한다. 나머지 미등록 포장 train은 배경 클래스로 학습한다.
- 공식 val의 학습 허용 품목만 사용한다. 미등록 검증 사진 중 최대 5%를 받아들이는 가장 낮은 판정 경계를 택하되, 세 클래스 중 다른 클래스의 점수가 동점 이상이면 보류한다. 검증용 등록 주스 정답률을 함께 기록한다.
- 모델 구조와 정규화, 학습 규칙을 아래와 같이 고정한다. 모델과 임계값을 파일에 저장한 뒤 공식 test를 한 번 평가한다. 모든 포장과 과일·채소를 채점하고, 모델 개발에서 제외한 종류의 포장 결과도 분리한다.
- 이번에 처음 채점하는 공식 카탈로그 포장 사진 전체도 별도로 평가한다. 등록품은 두 종 각 한 장이어서 현장 정답률 추정에는 부족하다. 분할별 원본 이미지 해시를 비교한다. 카탈로그와 매장 사진을 합산하지 않는다.

## 판별기

ImageNet-1K로 사전 학습된 torchvision ResNet-18의 평균 풀링 뒤 512차원 벡터를 동결한다. 전체 RGB 이미지를 224×224로 bilinear 리사이즈하고 ImageNet 채널 통계를 사용한다. 벡터를 L2 정규화한 뒤 사과·오렌지·배경 세 클래스의 선형 분류기를 학습한다. 각 클래스의 총 손실 가중치는 1/3이고, 가중치에 적용하는 L2 계수는 0.0003이다. 절편은 정규화하지 않는다. 학습된 두 주스 점수 중 높은 값에서 다른 주스와 배경 점수 중 큰 값을 뺀 값으로 수락을 결정한다. 점수는 확률로 해석하지 않는다.

새 모델은 실물 사진 파일을 입력받는 오프라인 경로로 제공한다. 시뮬레이터에 등록된 줄무늬 A/B는 별도의 품목이다. 실험 자료의 데이터셋 리비전은 `fc80ba90f803d79d0383df52c5a4ac5de99ff6fc`이고, 사전 학습 가중치의 SHA-256은 `f37072fd47e89c5e827621c5baffa7500819f7896bbacec160b1a16c560e07ec`이다. [데이터셋](https://github.com/marcusklasson/GroceryStoreDataset/tree/fc80ba90f803d79d0383df52c5a4ac5de99ff6fc) · [가중치 출처](https://pytorch.org/vision/stable/models/generated/torchvision.models.resnet18.html)

## 두 번째 실험의 사전 명세

첫 실험에서 과일·채소 오수락이 524/1,704로 늘어 포장에 인쇄된 무늬를 직접 대조하는 실험을 추가했다. Codex가 공식 train 이미지에서 각 맛 6장씩 앞면·옆면을 표시했다. 검증 사진에서 손으로 앞면을 가린 사례를 확인해 위에서 본 학습 사진을 각 맛 2장씩 더 등록했다. 한 옆면의 비슷한 색이 판정을 좌우하지 않도록 맛별 색 유사도의 중앙값을 쓴다. 등록 사진의 SIFT 특징과 입력 사진의 대응점으로 평면 변환을 구한다. 배경에 작게 보이는 포장은 중앙 위치·면적 조건으로 제외한다. 포장 종류가 확인된 영역의 색상 분포를 등록 자료와 비교해 맛을 구분한다. 자동 피킹에 연결하지 않고 사진 파일 한 장을 입력하는 별도 경로로 검증한다. [등록 영역](../configs/bravo-template-regions.json)

개발 점검에는 남은 train의 등록 사진과 기존에 사용한 공식 val 포장 부분집합을 쓴다. 설정을 고정한 다음 기존 test 포장·과일·채소와 카탈로그를 재평가한다. 두 번째 실험의 신규 대조군은 이전 두 실험에서 읽지 않은 공식 val 과일·채소 사진 전량이다. 개발 사진의 바이트 해시가 어느 평가 사진과도 겹치면 중단한다. 채택 기준은 거리 기준 강화 실험에 비해 등록 정답이 늘고, 미등록 포장 오수락이 36/727 이하, 과일·채소 오수락이 46/1,704 이하인 경우다.
