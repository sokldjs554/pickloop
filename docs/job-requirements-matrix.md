# 채용 요구사항 대응표

기준: 2026-11-18 확인한 [Wanted 395998](https://www.wanted.co.kr/wd/395998). 전체 원문 대조와 ID 정의는 [회사·공고 조사](research/company-and-role.md), 기존 소스·커밋·실행 여부는 [기존 프로젝트 감사](research/existing-projects.md)와 [증거 인덱스](research/repository-evidence.json)에 있다. 아래의 기존 근거는 저장소에서 확인한 구현/기록을 의미하며 사용자가 모두 직접 작성·실행했다는 뜻이 아니다.

지원자가 직접 수정·실행한 개발 seed 200은 [PR #1](https://github.com/sokldjs554/pickloop/pull/1)과 [전후 기록](experiments/retry-height/)으로 확인할 수 있다. 아래 실물 사진 분석·시뮬레이션·소프트웨어 연동 시험은 Codex가 실행했다. [분야별 결과와 원본](https://pickloop-robot-ops.ykh13571.chatgpt.site/evidence.html)

복구 정책의 동결 평가 576회는 PR #1 이전 소스로 실행했다. 각 조건에서 같은 예산의 단순 재시도·재관측·재계획을 비교할 수 있다. 더 이른 120회는 정책별 시도 예산이 달랐다. [4정책 실험 명세](ablation-protocol.md)
