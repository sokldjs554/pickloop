# 채용 요구사항 대응표

2026년 11월 26일에 [원티드 395998](https://www.wanted.co.kr/wd/395998)의 공개 페이지와 페이지 데이터에서 활성 상태 및 우대사항 4개를 재확인했다. 원문의 주요업무 5개 묶음을 14개, 자격요건 3개 묶음을 4개로 나눴다. 우대 4개와 [회사 소개의 공통 조건](https://www.wanted.co.kr/company/54714) 3개까지 아래에서 총 25개 행으로 대조했다. [출처와 항목 정의](research/company-and-role.md) · [기존 프로젝트 감사](research/existing-projects.md)

지원에서 보여줄 핵심은 시뮬레이션 피킹·복구, 실제 사진 평가, ROS 2 DDS 및 소프트웨어 PLC 통신이다. 실물 로봇 모델 배포, 실물 센서·그리퍼·도킹·충전과 PLC 시운전은 별도 경험이 필요하다. 사용자의 직접 실습 근거는 PADS와 개발 seed 200의 복구 규칙이고, 이번 KiCad 자료와 지도·경로 시험은 Codex가 만들고 검증했다.

지원자가 직접 수정·실행한 개발 seed 200은 [PR #1](https://github.com/sokldjs554/pickloop/pull/1)과 [전후 기록](experiments/retry-height/)으로 확인할 수 있다. 아래 실물 사진 분석·시뮬레이션·소프트웨어 연동 시험은 Codex가 실행했다. [분야별 결과와 원본](https://pickloop-robot-ops.ykh13571.chatgpt.site/evidence.html)

복구 정책의 동결 평가 576회는 PR #1 이전 소스로 실행했다. 각 조건에서 같은 예산의 단순 재시도·재관측·재계획을 비교할 수 있다. 더 이른 120회는 정책별 시도 예산이 달랐다. [4정책 실험 명세](ablation-protocol.md)
