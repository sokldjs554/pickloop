# 채용 요구사항 대응표

기준: 2026-11-18 확인한 [Wanted 395998](https://www.wanted.co.kr/wd/395998). 전체 원문 대조와 ID 정의는 [회사·공고 조사](research/company-and-role.md), 기존 소스·커밋·실행 여부는 [기존 프로젝트 감사](research/existing-projects.md)와 [증거 인덱스](research/repository-evidence.json)에 있다. 아래의 기존 근거는 저장소에서 확인한 구현/기록을 의미하며 사용자가 모두 직접 작성·실행했다는 뜻이 아니다.

`구현`은 해당 소스가 존재한다는 의미다. `검증` 열은 재현할 시험과 결과 파일을 가리키며, 시험 소스의 존재만으로 통과를 주장하지 않는다. 새 `runs/ablation-heldout`은 12 seed×12조건×4정책 576회 평가를 완료했으며 전체 원본을 공개했다. [4정책 실험 명세](ablation-protocol.md)를 따른다. 과거 `runs/final` 120회는 1회/3회 예산 차이를 포함해 복구 판단의 인과 증거로 해석하지 않는다. 최종 수치는 완료된 실행 원본의 집계만 따른다. 모바일·ROS2는 실제 통합 실행 원본을 확인했으며 해당 모듈 문서와 결과에 연결했다. 실물 검증은 수행하지 않았다.
